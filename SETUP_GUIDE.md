Follow these steps to get the platform running locally.

### 1. Backend Setup (`Crowdfunding-Server`)
1. **Install Dependencies:**
   ```bash
   cd Crowdfunding-Server
   npm install
   ```
2. **Run:**
   ```bash
   npm start
   ```

---

### 2. Frontend Setup (`Crowdfunding`)
1. **Install Dependencies:**
   ```bash
   cd ../Crowdfunding
   npm install
   ```
2. **Run:**
   ```bash
   npm run dev
   ```
